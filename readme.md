# 📚 Belajar-KAR

**Kelompok Antar Rombel (KAR) — Kelompok 8**

Repository ini merupakan tempat dokumentasi kegiatan belajar bersama Kelompok 8 dalam mendalami berbagai materi yang berkaitan dengan **Pengembangan Perangkat Lunak dan Gim (PPLG)**.

Melalui repository ini, setiap anggota kelompok dapat berbagi pengetahuan, mempelajari teknologi baru, melakukan praktik bersama, serta mendokumentasikan hasil pembelajaran dalam bentuk catatan, source code, maupun dokumentasi lainnya.

## 🎯 Tujuan

1. Meningkatkan pemahaman anggota kelompok terhadap bidang PPLG.
2. Menjadi wadah untuk belajar dan berbagi pengetahuan.
3. Mengembangkan kemampuan problem solving dan berpikir logis.
4. Meningkatkan keterampilan dalam pemrograman dan pengembangan perangkat lunak.
5. Mendokumentasikan setiap proses dan hasil pembelajaran.
6. Membangun kebiasaan berkolaborasi menggunakan Git dan GitHub.

## 💻 Ruang Lingkup Pembelajaran

Materi pembelajaran mencakup berbagai bidang yang berkaitan dengan PPLG, di antaranya:

| Bidang | Materi |
|---|---|
| Web Development | HTML, CSS, JavaScript, PHP, Laravel, React, Next.js |
| Backend Development | Node.js, Express.js, REST API |
| Database | MySQL, PostgreSQL, Supabase |
| Programming | JavaScript, PHP, Python, C# |
| Game Development | Unity, Godot, Game Design |
| UI/UX Design | Figma, Wireframe, Prototyping |
| Version Control | Git, GitHub |
| Software Engineering | SDLC, UML, ERD, Testing |
| Other | Materi lain yang relevan dengan PPLG |

Daftar tersebut tidak bersifat tetap dan dapat berkembang sesuai kebutuhan serta kesepakatan kelompok.

## 📂 Struktur Repository

Setiap laporan memiliki folder tersendiri dan dapat berisi sejumlah pertemuan.

```text
Belajar-KAR/
│
├── README.md
├── .gitignore
│
├── Laporan Ke-1/
│   ├── README.md
│   ├── Pertemuan 1/
│   ├── Pertemuan 2/
│   └── ...
│
├── Laporan Ke-2/
│   ├── README.md
│   ├── Pertemuan 1/
│   └── ...
│
└── ...
```

**Keterangan:**
- `Laporan Ke-n` merupakan dokumentasi dari satu periode laporan pembelajaran.
- `Pertemuan n` merupakan dokumentasi dari setiap kegiatan belajar.
- Jumlah pertemuan dalam satu laporan bersifat fleksibel.
- Setiap pertemuan dapat memiliki catatan materi, dokumentasi, latihan, dan source code.

## 📝 Dokumentasi Pembelajaran

Setiap pertemuan diharapkan memiliki dokumentasi yang mencakup:

- **Topik:** Materi yang dipelajari.
- **Tujuan:** Hal yang ingin dicapai dari pembelajaran.
- **Materi:** Penjelasan mengenai topik pembelajaran.
- **Praktik:** Implementasi atau percobaan yang dilakukan.
- **Hasil:** Hasil dari kegiatan pembelajaran.
- **Kesimpulan:** Hal yang diperoleh setelah pembelajaran.

## 🤝 Aturan Kontribusi

Seluruh anggota Kelompok 8 dapat berkontribusi dalam repository ini dengan ketentuan:

1. Gunakan nama folder dan file yang jelas.
2. Dokumentasikan setiap kegiatan pembelajaran dengan rapi.
3. Sertakan source code apabila terdapat praktik pemrograman.
4. Gunakan commit message yang deskriptif.
5. Jangan menghapus atau mengubah dokumentasi anggota lain tanpa koordinasi.
6. Pastikan kode yang diunggah tidak mengandung password, API key, atau informasi sensitif.

## 🌱 Penutup

Belajar bukan hanya tentang memahami teori, tetapi juga tentang mencoba, berdiskusi, berbagi, dan berkembang bersama.

Melalui **Belajar-KAR**, diharapkan seluruh anggota Kelompok 8 dapat terus meningkatkan kemampuan, memperluas wawasan, dan berkembang bersama dalam dunia Pengembangan Perangkat Lunak dan Gim.
